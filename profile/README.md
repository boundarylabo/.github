# 境界設計室 / Boundary LAB

メタバース空間の体験を設計する会社です。ミッションは「境界を越える体験を設計する」。
体験設計から販売・レンタル・運用支援までを手がけ、自社メタバース rezona で実践しています。

## rezona

自社ホスティングの Web メタバース。実験と実装の現場です。→ [rezona.jp](https://rezona.jp)
